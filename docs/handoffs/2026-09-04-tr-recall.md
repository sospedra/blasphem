# Handoff: Turkish recall

## Objective

Raise Turkish recall without breaking either validation gate.

Use targeted data and stronger Turkish features. Do not add bulk data first.

## Baseline

Source: `benchmark/runs/7cf3bbc.json`. The run used a dirty worktree.

| split | TP | FN | FP | TN | recall | precision |
|---|---:|---:|---:|---:|---:|---:|
| validation | 116 | 788 | 12 | 3,691 | 12.83% | 90.63% |
| test | 95 | 621 | 18 | 2,794 | 13.27% | 84.07% |

The manifest records 27,103 development rows. Corpus volume is not the first limit.

The current profile is `WordChar35V2`. Turkish uses `TurkishV2` normalization.

The current precision sits near the 90% gate. A lower boundary admits false positives.

## Working diagnosis

The fixed learner separates Turkish poorly. Agglutinative forms split lexical evidence.

The 250 live lexicon entries miss inflections and evasions. Some source labels may differ.

Treat both points as hypotheses. The audit must decide first.

## Work order

1. Audit every validation false positive.
2. Audit 200 stratified validation false negatives.
3. Record the score, length, and lexicon hits.
4. Ask a native reviewer to assign one error cause.
5. Keep all validation text outside development.

Use these cause labels:

- label mismatch
- inflection or suffix
- spelling evasion
- unseen insult
- implicit attack
- quote or report
- code switch
- model collision

Then run isolated ablations:

1. Keep the current model as the control.
2. Add a Turkish character-only profile.
3. Test longer character grams through length nine.
4. Test class-weighted linear training.
5. Keep the runtime artifact format unchanged.

Change one factor per run. Use the same validation rows and gates.

Add data only for audited gaps. Add development rows only.

Add inflected and evasive forms after native review. Propose matched clean controls.

For external data, follow `CONTRIBUTING.md`. Update both source records.

## Acceptance

- Validation recall shows a clear paired gain.
- Validation precision stays at least 90%.
- Validation false warnings stay at most 3%.
- The 15-language validation gates still pass.
- Existing behavior checks still pass.
- The report lists paired row changes.
- The report labels validation as tuned evidence.

Run `corpus-verify` after each corpus change.

Run validation during selection. Keep the test split sealed.

Freeze one candidate before the final test run.

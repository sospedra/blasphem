# Handoff: Chinese recall

## Objective

Raise Chinese recall without breaking either validation gate.

Add targeted data, lexical coverage, and Chinese character features.

## Baseline

Source: `benchmark/runs/7cf3bbc.json`. The run used a dirty worktree.

| split | TP | FN | FP | TN | recall | precision |
|---|---:|---:|---:|---:|---:|---:|
| validation | 13 | 359 | 1 | 381 | 3.49% | 92.86% |
| test | 17 | 344 | 1 | 379 | 4.71% | 94.44% |

The manifest records only 3,501 development rows. Chinese needs more targeted data.

The current `Char25V2` profile omits character unigrams. Chinese lexicon markers stay disabled.

The runtime comment reports 5% toxic lexicon coverage. Sparse coverage makes markers harmful.

## Working diagnosis

The corpus misses implicit attacks, homophones, and evasive forms. The model misses single-character clues.

The lexicon has 766 live entries. Entry count does not prove message coverage.

The current representation lacks enough signal. A larger broad lexicon alone will not fix it.

## Work order

1. Audit every validation false positive.
2. Audit 200 stratified validation false negatives.
3. Record the score, length, and lexicon hits.
4. Ask two native reviewers to resolve disputed labels.
5. Keep all validation text outside development.

Use these cause labels:

- direct insult
- identity attack
- implicit stereotype
- homophone or pun
- symbol or Latin evasion
- context-dependent attack
- quote or report
- model collision

Build reviewed minimal pairs for observed gaps. Each toxic row needs a hard clean neighbor.

Add licensed development rows for uncovered error groups. Prefer native social-message data.

For external data, follow `CONTRIBUTING.md`. Update both source records.

Expand conservative lexicon coverage after sense review. Measure message coverage after each batch.

Then run isolated ablations:

1. Keep `Char25V2` as the control.
2. Add character unigrams in a new profile.
3. Test separate Han and Latin feature namespaces.
4. Retest lexicon markers after coverage rises.
5. Combine only proven factors.

Keep marker strength learned by the model. Do not add a direct lexicon verdict.

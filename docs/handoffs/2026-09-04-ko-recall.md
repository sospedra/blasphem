# Handoff: Korean recall

## Objective

Raise Korean recall without breaking either validation gate.

Fix Korean features before adding more data.

## Baseline

Source: `benchmark/runs/7cf3bbc.json`. The run used a dirty worktree.

| split | TP | FN | FP | TN | recall | precision |
|---|---:|---:|---:|---:|---:|---:|
| validation | 1,691 | 2,160 | 146 | 4,729 | 43.91% | 92.05% |
| test | 4,562 | 5,521 | 412 | 11,393 | 45.24% | 91.72% |

The manifest records 78,049 development rows. Korean does not need bulk data.

The false-warning rate is 2.995%. The 3% gate blocks a lower boundary.

The current `Char25V2` profile ignores spaces. It joins neighboring Korean words.

`KoreanV2` does not decompose precomposed syllables into Jamo.

## Working diagnosis

The feature profile loses word boundaries. It also misses decomposed slang forms.

More corpus rows will repeat the same representation limit. Fix features first.

## Work order

1. Audit all 146 validation false positives.
2. Audit 200 stratified validation false negatives.
3. Record the score, length, and lexicon hits.
4. Ask a native reviewer to assign one error cause.
5. Keep all validation text outside development.

Use these cause labels:

- spaced phrase collision
- slang or abbreviation
- decomposed Hangul
- spelling evasion
- identity attack
- context-dependent attack
- quote or report
- label mismatch

Create a Korean-only feature profile. Preserve the current profile value.

Run this factorial ablation:

1. Keep current `Char25V2` as the control.
2. Treat whitespace as a character-gram boundary.
3. Add Jamo grams in a separate namespace.
4. Combine whitespace boundaries and Jamo grams.

Keep original Hangul syllable grams. Jamo grams must add signal.

Use choseong, jungseong, and jongseong units. Mark absent jongseong explicitly.

Add targeted development rows only after the feature ablation. Cover residual error groups.

Review any new conservative lexicon form. Propose matched clean controls.
